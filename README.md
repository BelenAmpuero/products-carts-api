Este proyecto consiste en el desarrollo de una API de e-commerce utilizando Node.js, Express y MongoDB, 
enfocada en la gestión de productos y carritos de compra. La aplicación permite realizar operaciones CRUD completas, 
manejar persistencia de datos mediante Mongoose y FileSystem, implementar paginación, filtros y ordenamiento de productos.

El sistema está organizado con una arquitectura modular basada en rutas, modelos y DAOs, 
simulando un entorno real de desarrollo backend. También incluye vistas dinámicas para visualizar productos, 
detalles y carritos, permitiendo una experiencia más interactiva y cercana a una aplicación de comercio electrónico profesional.
